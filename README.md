# Flux Visuals releases

Release files for the Flux Launcher: `manifest.json` lists the Flux versions, and each GitHub
release carries the matching `fluxvisuals-<version>.jar`. The launcher checks every jar against
the sha256 in the manifest before installing it.

The Flux source code is not in this repository.

## Flux Launcher 0.1.7

- Windows: [FluxLauncher.exe](https://github.com/phasepoemshield/flux-releases/releases/download/launcher-v0.1.7/FluxLauncher.exe)
- macOS (Apple Silicon): [FluxLauncher.dmg](https://github.com/phasepoemshield/flux-releases/releases/download/launcher-v0.1.7/FluxLauncher.dmg)

Install once; the launcher updates itself and Flux.
